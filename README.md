# مخزني Pro v2

نسخة سطح مكتب مبنية على Electron + SQLite.

## أهم التحسينات
- SQLite مع WAL بدل localStorage كمصدر البيانات الأساسي.
- تسجيل دخول آمن باستخدام bcrypt، والجلسة محفوظة في العملية الرئيسية وليس localStorage.
- قاعدة بيانات داخل مجلد بيانات التطبيق في userData.
- نسخ احتياطي JSON من داخل النظام.
- بحث بالباركود، مع دعم barcode على المنتج أو داخل variant.
- دعم `variants` داخل المنتج: `{ id, color, size, barcode, quantity, minStock }`.
- تقارير صافي الربح = المبيعات - تكلفة البضاعة - المصروفات.
- سجل تدقيق Audit Log.
- تجهيز لبناء Windows NSIS وPortable.

## التشغيل
```bash
npm install
npm start
```
